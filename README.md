# BotBoy

A Python command-line assistant built from scratch.

## Features

- Memory System
- Calculator
- To-Do List
- Jokes
- Date & Time
- Chat history
- Website Opener

## Commands

- help
- joke
- show list
- to do list
- open youtube
- what is my name
- display history
- remove history
- time
- exit
